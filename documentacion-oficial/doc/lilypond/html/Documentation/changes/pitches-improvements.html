Pitches improvements

  • The new \approximatePitch command creates notes of approximate pitch. 
    \relative c'' {
  e4 f g \approximatePitch c
}
  • Certain spurious change clefs have been fixed. 
    {
  R1
  \clef treble
  R1
}
