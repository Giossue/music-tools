Release numbers 发行号

有两套 LilyPond 的发行版集合：稳定版和不稳定的开发版。 稳定版的 ‘次’ 版本号是偶数（如 2.8、2.10、2.12）， 开发版的 ‘次’ 版本号是奇数（如 2.15、2.17、2.19）。

贡献者指南

LilyPond 的开发是一个相当复杂的问题。为了帮助新的贡献者， 且同时保持整个系统（近乎）稳定，我们编纂了开发任务手册。
