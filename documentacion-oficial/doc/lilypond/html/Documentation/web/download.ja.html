GNU/Linux

Generic Packages or Distribution-Specific Packages?

Many distributions include LilyPond within their normal package repositories. However, these may be significantly older than the current stable version. If this is the case for you, we strongly recommend that you use our generic packages.

Downloads for Generic Packages

  • GNU/Linux x86_64: LilyPond 2.26.0

Windows

Downloads for Generic Packages

These binaries work under current Windows versions (Windows 7 and Windows 8 are not supported).

  • Windows x86_64: LilyPond 2.26.0

macOS

Downloads for Generic Packages

These binaries work on macOS 10.15 (Catalina) and higher. For older macOS versions, please use MacPorts.

  • macOS x86_64: LilyPond 2.26.0

Using a Package Manager

  • MacPorts, a package manager for macOS, has a LilyPond port.
  • Homebrew, another package manager for macOS, has a LilyPond formula.
