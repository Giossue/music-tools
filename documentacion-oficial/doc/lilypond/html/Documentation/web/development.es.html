Nota: Éstas son las versiones inestables de desarrollo. Si tiene la más ligera duda acerca de cómo usar o instalar LilyPond, le pedimos encarecidamente que utilice la descarga estable, y lea los manuales estables.

Números de versión

Existen dos conjuntos de lanzamientos para LilyPond: lanzamientos estables, y lanzamientos inestables de desarrollo. Las versiones estables tienen un número de versión ‘menor’ par (p.ej., 2.14, 2.16, 2.18). Las versiones de desarrollo tienen un número ‘menor’ de versión impar (p.ej., 2.15, 2.17, 2.19).

Guía del colaborador

El desarrollo de LilyPond es un asunto bastante complicado. LilyPond es un proyecto grande y (más o menos) estable. Para poder ayudar a los nuevos colaboradores, y para mantener todo el sistema (más o menos) estable, hemos escrito un manual para los colaboradores.

  • Guía del colaborador (HTML seccionado) − el manual está dividido en muchas páginas HTML.
      (una descarga pequeña por cada página)
  • Guía del colaborador (HTML monolítico) − lea este manual como una sola página HTML enorme.
      (una sola descarga grande, 740K)
  • contributor.pdf − descárguelo como un archivo en formato PDF.
      (una sola descarga grande, 832K)

Pruebas de regresión

  • Pruebas visuales de regresión: Pruebas de regresión de esta versión que contienen información visual útil. (versión PDF)
  • Pruebas de regresión de MIDI: Pruebas de regresión de esta versión relativas a la salida MIDI. (versión PDF)
  • Otras pruebas de regresión: Pruebas de regresión de esta versión sin salida visual. (versión PDF)
  • Pruebas de MusicXML: Pruebas de MusicXML de esta versión (convertidas con musicxml2ly). (versión PDF)
  • Pruebas de ABC: Pruebas de notación ABC de esta versión (convertidas con abc2ly). (versión PDF)
