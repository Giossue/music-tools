Para nuevos usuarios

Entrada de texto: LilyPond es un sistema de grabado musical basado en texto; se parece más a un lenguaje de programación que a un programa gráfico de edición de partituras. Lea esto para comprender el manejo básico de LilyPond.

Manual de aprendizaje: Esta amable introducción a LilyPond le muestra cómo instalarlo y le orienta por los primeros pasos con el programa.

Para los usuarios que se actualizan a partir de una versión anterior

Cambios: Qué hay de nuevo en LilyPond 2.26.0.

Manual de utilización del programa: Explica cómo ejecutar convert-ly para actualizar, sin esfuerzo, documentos de entrada existentes escritos para versiones anteriores.

Manual de aprendizaje: El procedimiento de instalación que se explica en el tutorial permite la instalación de varias versiones distintas de LilyPond al mismo tiempo, sin complicaciones.

GNU/Linux

¿Paquetes genéricos, o paquetes específicos de la distribución?

Muchas distribuciones incluyen a LilyPond dentro de sus repositorios normales de paquetes. Sin embargo, con frecuencia estos son significativamente más antiguos que la versión estable actual. Si es su caso, le recomendamos encarecidamente utilice nuestros paquetes genéricos.

Descarga de paquetes genéricos

  • GNU/Linux x86_64: LilyPond 2.26.0

Windows

Descarga de paquetes genéricos

Estos archivos se pueden ejecutar bajo versiones actuales de Windows (Windows 7 y Windows 8 no están contemplados).

  • Windows x86_64: LilyPond 2.26.0

macOS

Descarga de paquetes genéricos

Estos archivos binarios se pueden ejecutar sobre macOS 10.15 (Catalina) o superior. Para versiones de macOS más antiguas, utilice MacPorts.

  • macOS x86_64: LilyPond 2.26.0

Instalación

  • MacPorts, un gestor de paquetes para macOS, tiene un port de LilyPond.
  • Homebrew, otro gestor de paquete para macOS, tiene una fórmula de LilyPond.
